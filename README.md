# Bitcoin Wallet Generator


## Requirements:
- **Node.js**
- **npm**

## Folder Structure

### Before Installation

```text
bitcoin-wallet-app/
├── index.html
├── js/
│   └── app.js
└── css/
    └── style.css
```

### After Installation & Build

```
bitcoin-wallet-app/
├── index.html
├── js/
│   └── app.js
│   └── app.bundle.js
├── css/
│   └── style.css
├── package.json
├── package-lock.json
└── node_modules/
```

## Installation & run

```
npm install
npm run build
npx serve .
```
